پیش از شروع: معماری و سرورها

AntiMage از یک سرور مدیریت (Master) و یک یا چند سرور VPN (Node) تشکیل می‌شود. ابتدا پنل را نصب می‌کنید؛ بعد از داخل پنل برای هر Node بسته اتصال یکتا می‌سازید و همان بسته را هنگام نصب نود وارد می‌کنید.

۱ · Masterپنل، پایگاه داده و مدیریت
۲ · Nodeپروتکل‌های VPN و حسابداری
۳ · کاربراشتراک یا پروفایل اتصال
MasterUbuntu/Debian به‌روز، root یا sudo، اینترنت و systemd برای نصب باینری؛ حداقل پیشنهادی ۱ هسته CPU و ۱GB RAM.
NodeLinux، root/sudo، IP قابل دسترس از Master، ساعت درست و دسترسی فایروال برای پورت‌های پروتکل انتخابی.
دامنهبرای استفاده واقعی، دامنه‌ای که به IP سرور Master اشاره کند و HTTPS معتبر آماده کنید.
امنیت: پورت مدیریت را عمومی نکنید. بسته اتصال Node محرمانه است؛ آن را در چت، تصویر یا مخزن عمومی نفرستید. مسیر این آموزش باینری است؛ روش Docker در پایان آمده و این دو روش را در یک مسیر نصب مخلوط نکنید.

۱. نصب پنل Master (باینری)

  1. با SSH به سرور Master وصل شوید و ابزارهای پایه را نصب کنید.
SSH · MASTER
sudo apt update
sudo apt install -y curl ca-certificates
  1. نصب‌کننده رسمی را اجرا کنید. گزینه latest آخرین نسخه پایدار را نصب می‌کند.
INSTALL · MASTER
curl -fsSL https://raw.githubusercontent.com/devprogrmer/AntiMage/main/scripts/antimage/antimage-binary.sh \
  | sudo bash -s -- install --version latest
  1. پرسش‌های نصب‌کننده را تا پایان دنبال کنید و تنظیمات پایگاه داده، دامنه و TLS را متناسب با سرور انتخاب کنید.
  2. فعال بودن سرویس و نبود خطای شروع را بررسی کنید.
VERIFY · MASTER
sudo systemctl status antimage --no-pager
sudo journalctl -u antimage -n 100 --no-pager
مسیر پیش‌فرض: برنامه /opt/antimage، داده و بکاپ /var/lib/antimage، سرویس antimage.service و درگاه پنل 8000.

۲. مدیر اولیه، ورود و HTTPS

  1. روی سرور مدیر نخست را بسازید؛ رمز نمونه را با یک رمز طولانی و یکتا جایگزین کنید. رمز واقعی را در سایت یا اسکرین‌شات ننویسید.
FIRST ADMIN
sudo antimage-cli admin create --username admin --role full_access --password 'REPLACE_WITH_A_LONG_UNIQUE_PASSWORD'
  1. برای دسترسی موقت، IP سرور را جایگزین کنید و در فایروال پورت 8000 را فقط برای IP خودتان باز بگذارید.
TEMPORARY PANEL URL
http://SERVER_IP:8000/dashboard/login
  1. برای دامنه‌ای مانند panel.example.com رکورد DNS از نوع A به IP عمومی Master بسازید؛ اگر IPv6 دارید، AAAA را نیز تنظیم کنید.
  2. دامنه و SSL را در تنظیمات/نصب‌کننده AntiMage فعال کنید؛ پس از معتبرشدن گواهی با HTTPS وارد شوید.
پس از راه‌اندازی HTTPS، درگاه خام پنل را برای همه اینترنت باز نگذارید. دسترسی را به reverse proxy یا IPهای مورداعتماد محدود کنید.

۳. ساخت نود در پنل و نصب روی سرور

  1. در پنل به «نودها / Nodes» بروید و افزودن را بزنید. نام نود، IP/دامنه قابل دسترس از Master و پورت کنترل را وارد و ذخیره کنید.
  2. از جزئیات نود، بسته کامل نصب/اتصال را کپی کنید. آن را فقط در نشست SSH همان سرور Node وارد کنید.
  3. به سرور Node با SSH وصل شوید و نصب‌کننده باینری پایدار را اجرا کنید.
SSH · NODE
sudo apt update
sudo apt install -y curl ca-certificates
curl -fsSL https://raw.githubusercontent.com/devprogrmer/AntiMage/main/scripts/antimage/antimage-node-binary.sh \
  | sudo bash -s -- install --version latest
  1. وقتی نصب‌کننده درخواست کرد، بسته کامل Node را همان‌جا وارد کنید. پورت پیش‌فرض کنترل 62050 و پورت Xray API 62051 است.
  2. فایروال را طوری تنظیم کنید که Master به پورت کنترل Node برسد؛ Xray API را عمومی نکنید و فقط پورت پروتکل‌های موردنیاز را باز کنید.
  3. وضعیت سرویس و لاگ‌ها را بررسی کنید.
VERIFY · NODE
sudo systemctl status antimage-node --no-pager
sudo journalctl -u antimage-node -n 100 --no-pager
بسته اتصال را در فرمان، چت یا ایمیل قرار ندهید؛ فقط در ورودی نصب‌کننده داخل SSH نود بچسبانید. چند نود روی یک سرور باید نام، مسیر داده، پورت و بسته مجزا داشته باشند.

۴. تأیید نود و اولین آزمایش

  1. به پنل برگردید و تا نمایش Online/Connected صبر کنید. اگر Offline است، نشانی نود، ساعت دو سرور و دسترسی Master به پورت کنترل را بررسی کنید.
  2. یک سرویس و inbound روی نود بسازید؛ پروتکل و پورت را انتخاب و تنظیمات را اعمال کنید.
  3. یک کاربر آزمایشی با حجم کم و انقضای کوتاه بسازید، اشتراک/QR را بگیرید و با کلاینت سازگار وصل شوید.
  4. اتصال، افزایش مصرف و به‌روزرسانی آمار در پنل را تأیید کنید؛ تا پیش از موفقیت آزمایش، کاربران واقعی را منتقل نکنید.
Node آفلاینوضعیت systemd، گواهی/بسته، آدرس، پورت کنترل، ساعت سرورها، فایروال و لاگ Node را بررسی کنید.
کاربر وصل نمی‌شودوضعیت و انقضای کاربر، سهمیه، سلامت نود، سرویس/inbound، پورت و سازگاری کلاینت را بررسی کنید.

عیب‌یابی اولیه

این فرمان‌ها نصب‌کننده رسمی AntiMage را دریافت می‌کنند. پیش از اجرای مجدد روی سرور موجود، وضعیت و نسخه را بررسی کنید تا نصب ناخواسته انجام نشود.

Before you begin: servers and architecture

AntiMage uses a control server (Master) and one or more VPN servers (Nodes). Install the panel first, create a unique node enrollment bundle in it, and enter that bundle when installing the Node agent.

1 · MasterPanel, database, management
2 · NodeVPN protocols and accounting
3 · UserSubscription or client profile
MasterUpdated Ubuntu/Debian, root or sudo, internet, and systemd for binary installs. Recommended minimum: 1 CPU core and 1 GB RAM.
NodeLinux, root/sudo, an address reachable from Master, correct system time, and firewall access for the protocols you enable.
DomainFor production, prepare a domain pointing to Master and a valid HTTPS setup.
Security: Do not expose the management port to everyone. Keep the node bundle secret. This guide uses binary mode; Docker is covered at the end. Do not mix modes in one install directory.

1. Install the Master panel (binary)

  1. Connect to Master over SSH and install base tools.
SSH · MASTER
sudo apt update
sudo apt install -y curl ca-certificates
  1. Run the official installer. latest selects the latest stable release.
INSTALL · MASTER
curl -fsSL https://raw.githubusercontent.com/devprogrmer/AntiMage/main/scripts/antimage/antimage-binary.sh \
  | sudo bash -s -- install --version latest
  1. Follow the prompts and select database, domain, and TLS settings for your server.
  2. Verify the service is active and check startup logs.
VERIFY · MASTER
sudo systemctl status antimage --no-pager
sudo journalctl -u antimage -n 100 --no-pager
Default paths: app /opt/antimage, data/backups /var/lib/antimage, service antimage.service, panel port 8000.

2. First admin, sign-in, and HTTPS

  1. Create the first administrator on the server. Replace the sample with a long unique password. Never put your real password on this website or in a screenshot.
FIRST ADMIN
sudo antimage-cli admin create --username admin --role full_access --password 'REPLACE_WITH_A_LONG_UNIQUE_PASSWORD'
  1. For temporary access, replace the server IP below and restrict port 8000 to your own address in the firewall.
TEMPORARY PANEL URL
http://SERVER_IP:8000/dashboard/login
  1. Create an A DNS record for panel.example.com pointing to the Master public IP; add AAAA if using IPv6.
  2. Configure the domain and SSL in AntiMage settings or the installer. Sign in over HTTPS after the certificate is valid.
Once HTTPS works, do not leave the raw panel listener open to everyone. Restrict it to a reverse proxy or trusted management IPs.

3. Create a node in the panel and install it

  1. Open Nodes in the panel, choose Add, enter a name, address reachable from Master, and control port, then save.
  2. Copy the full install/enrollment bundle from that node's details. Use it only in the SSH session on that Node.
  3. Connect to the Node over SSH and run the stable binary installer.
SSH · NODE
sudo apt update
sudo apt install -y curl ca-certificates
curl -fsSL https://raw.githubusercontent.com/devprogrmer/AntiMage/main/scripts/antimage/antimage-node-binary.sh \
  | sudo bash -s -- install --version latest
  1. When prompted, paste the complete node bundle. Default Node control and Xray API ports are 62050 and 62051.
  2. Allow Master to reach the Node control port. Do not expose the Xray API publicly; open only protocol ports you need.
  3. Verify the Node service and logs.
VERIFY · NODE
sudo systemctl status antimage-node --no-pager
sudo journalctl -u antimage-node -n 100 --no-pager
Never put the enrollment bundle in a command, chat, or email. Paste it only into the waiting installer prompt in the Node SSH session. Multiple Nodes on one host need unique names, data paths, ports, and bundles.

4. Verify the node and test the first connection

  1. Return to the panel and wait for Online/Connected. If offline, check the saved address, both system clocks, and Master-to-Node access to the control port.
  2. Create a service and inbound on the Node, select a protocol and port, then apply the configuration.
  3. Create a test user with a small quota and short expiry. Get its subscription/QR and connect with a compatible client.
  4. Confirm the connection works, usage increases, and the panel updates the accounting values. Do not move real users before the test succeeds.
Node is offlineCheck the systemd service, bundle/certificate, address, control port, clocks, firewall, and Node logs.
User cannot connectCheck account status, expiry, quota, Node health, service/inbound, protocol port, and client compatibility.

First-line troubleshooting

Panel will not openCheck antimage status/logs, port 8000, DNS, TLS, and reverse proxy.
Node is offlineCheck antimage-node, correct bundle, address/control port, and both firewalls.
Inbound did not applyRead the panel operation result and Node logs; do not restart services without a reason.

These commands download the official AntiMage installer. Before rerunning an installer on an existing server, verify its current state and version.

Перед началом: серверы и схема

AntiMage состоит из сервера управления (Master) и одного или нескольких VPN-серверов (Node). Сначала установите панель, затем создайте в ней уникальный пакет подключения узла и введите его в установщике Node.

1 · MasterПанель, база данных, управление
2 · NodeVPN-протоколы и учёт трафика
3 · ПользовательПодписка или профиль клиента
MasterОбновлённый Ubuntu/Debian, root или sudo, интернет, systemd для бинарной установки. Рекомендуется от 1 CPU и 1 ГБ RAM.
NodeLinux, root/sudo, адрес доступный с Master, правильное время и firewall для нужных протоколов.
ДоменДля production подготовьте домен, указывающий на Master, и HTTPS.
Безопасность: Не открывайте порт управления всем. Пакет Node храните в секрете. Здесь описана бинарная установка; вариант Docker приведён в конце. Не смешивайте режимы в одном каталоге.

1. Установка панели Master (бинарная)

  1. Подключитесь к Master по SSH и установите базовые инструменты.
SSH · MASTER
sudo apt update
sudo apt install -y curl ca-certificates
  1. Запустите официальный установщик. latest означает последнюю стабильную версию.
INSTALL · MASTER
curl -fsSL https://raw.githubusercontent.com/devprogrmer/AntiMage/main/scripts/antimage/antimage-binary.sh \
  | sudo bash -s -- install --version latest
  1. Следуйте запросам установщика и выберите параметры базы, домена и TLS для вашего сервера.
  2. Проверьте состояние службы и журнал запуска.
VERIFY · MASTER
sudo systemctl status antimage --no-pager
sudo journalctl -u antimage -n 100 --no-pager
Пути по умолчанию: приложение /opt/antimage, данные и резервные копии /var/lib/antimage, служба antimage.service, порт панели 8000.

2. Первый администратор, вход и HTTPS

  1. Создайте первого администратора на сервере. Замените пример длинным уникальным паролем. Не размещайте настоящий пароль на сайте и скриншотах.
FIRST ADMIN
sudo antimage-cli admin create --username admin --role full_access --password 'REPLACE_WITH_A_LONG_UNIQUE_PASSWORD'
  1. Для временного доступа укажите IP сервера вместо SERVER_IP и разрешите порт 8000 только со своего адреса.
TEMPORARY PANEL URL
http://SERVER_IP:8000/dashboard/login
  1. Создайте DNS-запись A для panel.example.com, указывающую на публичный IP Master; для IPv6 добавьте AAAA.
  2. Настройте домен и SSL в параметрах AntiMage или установщике. После проверки сертификата используйте HTTPS.
После включения HTTPS не оставляйте порт панели общедоступным. Ограничьте доступ reverse proxy или доверенными IP.

3. Создание узла в панели и установка на сервер

  1. Откройте «Nodes» в панели, выберите добавление, укажите имя, адрес доступный с Master и порт управления, затем сохраните.
  2. Скопируйте полный пакет установки/регистрации из сведений узла. Используйте его только в SSH-сеансе этого Node.
  3. Подключитесь к Node по SSH и запустите стабильный бинарный установщик.
SSH · NODE
sudo apt update
sudo apt install -y curl ca-certificates
curl -fsSL https://raw.githubusercontent.com/devprogrmer/AntiMage/main/scripts/antimage/antimage-node-binary.sh \
  | sudo bash -s -- install --version latest
  1. Когда установщик запросит данные, вставьте полный пакет Node. Порты по умолчанию: управление 62050, Xray API 62051.
  2. Разрешите Master доступ к порту управления Node. Не публикуйте Xray API; откройте только порты нужных протоколов.
  3. Проверьте службу и журнал.
VERIFY · NODE
sudo systemctl status antimage-node --no-pager
sudo journalctl -u antimage-node -n 100 --no-pager
Не помещайте пакет регистрации в команду или сообщение. Введите его только в ожидающий ввод установщик в SSH-сеансе Node. Для нескольких узлов на одном сервере нужны отдельные имена, каталоги, порты и пакеты.

4. Проверка узла и первое тестовое подключение

  1. Вернитесь в панель и дождитесь Online/Connected. Если Node Offline, проверьте адрес, системное время серверов и доступ Master к порту управления.
  2. Создайте сервис и inbound на Node, выберите протокол и порт, примените конфигурацию.
  3. Создайте тестового пользователя с небольшой квотой и коротким сроком действия, получите подписку/QR и подключитесь совместимым клиентом.
  4. Убедитесь, что соединение работает, трафик увеличивается, а статистика обновляется. Не переносите реальных пользователей до успешного теста.
Node не в сетиПроверьте systemd-службу, пакет/сертификат, адрес/порт, время, firewall и журнал Node.
Пользователь не подключаетсяПроверьте статус, срок и квоту, Node, сервис/inbound, порт протокола и клиент.
