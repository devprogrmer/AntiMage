В разделе Settings находятся общие параметры панели и интеграций. Доступные вкладки и действия зависят от разрешений администратора и режима установки.

<p class="am-panel-actions"><a class="am-panel-button" data-primary="true" href="#" data-panel-route="/settings#panel">Открыть настройки</a></p>

## Перед изменением параметров

- Настройки общие: изменение может повлиять на других администраторов, ссылки подписки, историю трафика и операции узлов.
- Кнопка **Save Settings** применяет все несохранённые изменения во всех вкладках. Она становится активной после изменения параметров; переход между вкладками не отменяет правки.
- Перед импортом данных, изменением шаблонов подписки или обслуживанием создайте актуальную резервную копию на Dashboard.
- Параметры, помеченные как доступные только для binary, не работают в Docker.

## Вкладка Panel {#panel-tab}

<p class="am-panel-actions"><a class="am-panel-button" href="#" data-panel-route="/settings#panel">Открыть вкладку Panel</a></p>

### Формат ссылки подписки по умолчанию

Определяет ссылку, которая по умолчанию показывается в панели. Другие поддерживаемые форматы продолжают работать.

| Формат | Назначение |
| --- | --- |
| `username/key` | Понятный адрес с именем пользователя и ключом. |
| Только `key` | Короткая ссылка без имени пользователя. |
| `token` | Ссылка с токеном для интеграций и существующих сценариев клиентов. |

### Параметры Runtime

| Параметр | Назначение | Особенность |
| --- | --- | --- |
| **Dashboard path** | URL-путь панели, например `/dashboard/`. | Одновременно обновите обратный прокси и закладки, иначе панель может стать недоступной. |
| **Subscription read-only mode** | Отдаёт подписки без обновления метаданных последнего использования. | Полезно за внешним кэшем, монитором или пробой; данные о последнем обращении будут неполными. |
| **Record node usage** | Сохраняет историю трафика узлов для страницы Usage. | Включает отчёты по узлам и увеличивает объём записей и хранения в БД. |
| **Record user usage samples** | Сохраняет выборки по пользователям, администраторам и сервисам. | Включает подробную историю, но увеличивает частоту записи в БД. |
| **Enable API docs** | Включает встроенный OpenAPI/Swagger по адресу `/docs`. | API по-прежнему требует аутентификации и соответствующих разрешений. |

Оставьте сбор истории включённым, если используете графики. Чтобы снизить записи в БД, отключайте только те выборки, которые вам не нужны.

### phpMyAdmin

Раздел phpMyAdmin доступен при использовании MySQL или MariaDB. Он позволяет установить или включить phpMyAdmin, открыть его в панели, выбрать путь и использовать учётную запись базы AntiMage либо отдельные данные входа. Ограничьте доступ к странице и не раскрывайте пароль базы другим администраторам.

## Обслуживание и резервная копия Dashboard {#dashboard-maintenance}

<p class="am-panel-actions"><a class="am-panel-button" href="#" data-panel-route="/">Открыть Dashboard</a></p>

Версия панели и действия **Restart panel**, **Backup** и **Update panel** находятся в заголовке **System overview** на Dashboard. Для действий на хосте нужны соответствующие права администратора и binary-установка.

### Обслуживание

- **Update panel** открывает меню обслуживания: можно выбрать канал, последний релиз или dev-сборку. Для dev-сборки требуется дополнительное подтверждение, поскольку там могут быть незавершённые изменения и миграции.
- Не закрывайте окно прогресса обновления: в нём отображается ход операции, а страница обновится после запуска панели.
- **Soft Reload** перечитывает конфигурацию панели без намеренного прерывания соединений.
- **Restart panel** временно делает Dashboard и API недоступными.
- В Docker хостовые операции недоступны; управляйте жизненным циклом контейнера вне панели.

### Резервная копия

Резервные копии AntiMage экспортируются в переносимом формате `.ambackup`, совместимом с SQLite, MySQL и MariaDB. Панель определяет формат архива по манифесту.

| Область | Что входит |
| --- | --- |
| **Только база данных** | Записи базы AntiMage; системные файлы не меняются. |
| **База данных + файлы AntiMage** | База и каталоги конфигурации и данных, включая `/etc/antimage` и `/var/lib/antimage`. |

Откройте **Backup** рядом с **Restart panel** и выберите экспорт или импорт. При экспорте задаётся область. При импорте панель определяет тип архива автоматически: база данных заменяется всегда, а файлы AntiMage восстанавливаются только если они есть в архиве. Импорт заменяет текущие данные — проверьте файл и сохраните отдельную рабочую копию. Импорт и экспорт доступны только в binary-режиме.

## Вкладка Telegram {#telegram-tab}

<p class="am-panel-actions"><a class="am-panel-button" href="#" data-panel-route="/settings#telegram">Открыть вкладку Telegram</a></p>

1. Создайте бота и вставьте **Bot API Token**. Храните токен как пароль.
2. Добавьте числовые **Admin Chat IDs**. Для журналов в другом чате задайте **Logs Chat ID**.
3. Для форумной группы включите соответствующую настройку и укажите ID тем.
4. Настраивайте прокси, только если сервер панели не может подключиться к Telegram напрямую.
5. Перед включением уведомлений и расписания резервных копий отправьте тестовое сообщение.

### Периодическая резервная копия

Запланированное копирование через Telegram доступно только в binary-установке. Выберите область (только БД или полная копия), интервал и при необходимости отдельный чат. **Send backup now** позволяет быстро проверить разрешения и доставку файла.

### Уведомления

Группы уведомлений охватывают события пользователей, администраторов, узлов, входа и ошибок. Включайте только события, требующие реакции: поток всех сообщений в один чат затрудняет просмотр важных сигналов.

## Вкладка Subscriptions {#subscriptions-tab}

<p class="am-panel-actions"><a class="am-panel-button" href="#" data-panel-route="/settings#subscriptions">Открыть вкладку Subscriptions</a></p>

Глобальные параметры применяются ко всем администраторам, если для администратора не задано переопределение.

- **Subscription URL prefix** задаёт публичный домен для ссылок; оставьте пустым для относительных URL.
- **Custom templates directory** задаёт каталог загрузки шаблонов Jinja.
- **Subscription profile title**, **Support URL** и **Profile update interval** передаются совместимым клиентам и показываются на странице подписки.
- Шаблоны клиентов выбирают файлы страницы подписки, домашней страницы и форматов Clash, V2Ray, Happ, Incy, Sing-box и Mux.
- **Subscription alias URLs** добавляет совместимые псевдонимы маршрутов — по одному на строку.
- **Subscription ports** добавляет порты к URL подписки.
- Переключатели JSON задают специальное поведение для поддерживаемых клиентов.

Переопределения администратора используйте только при необходимости. Общие значения оставляйте глобальными; для возврата к ним нажмите **Reset overrides**.

## Вкладка SSL {#ssl-tab}

<p class="am-panel-actions"><a class="am-panel-button" href="#" data-panel-route="/settings#ssl">Открыть вкладку SSL</a></p>

Вкладка SSL показывает сохранённые сертификаты и позволяет искать по домену, провайдеру или состоянию. Фильтр срока действия помогает найти сертификаты, истекающие в ближайшие семь дней.

- **Get new SSL** открывает единый диалог для Let's Encrypt, ZeroSSL или ручного импорта PEM. Для ACME укажите email и домены; ручной импорт требует домен, `fullchain.pem` и `privkey.pem`.
- Выпуск ACME требует открытого порта 80. Включённые сертификаты выбираются по SNI; сертификат из ENV остаётся резервным.
- Действия строки позволяют продлить подходящий сертификат, включить/выключить TLS, отозвать или удалить его. Отзыв и удаление могут прервать TLS-соединения для домена и не меняют DNS.

## Рекомендуемый порядок настройки панели

1. Настройте Dashboard и формат ссылок по умолчанию во вкладке **Panel**.
2. Экспортируйте исходную копию из меню **Backup** на Dashboard.
3. Проверьте Telegram перед включением уведомлений о событиях.
4. Настройте глобальные значения подписок и добавляйте переопределения только по необходимости.
5. Выпустите или импортируйте сертификаты во вкладке **SSL** и проверьте ссылки в поддерживаемых клиентах.
