При создании или редактировании пользователя сервис можно выбрать автоматически по тегу входящего подключения.

## Порядок действий

1. Откройте Services, выберите сервис и создайте **Service inbound** с тегом формата `setservice-<service_id>`.
2. В форме создания/редактирования пользователя, если сервис не выбран, добавьте в список только этот тег.
3. Панель назначит связанный сервис и применит его входящие подключения и хосты.
4. Если сервис выбран вручную, список входящих подключений игнорируется и применяются параметры выбранного сервиса.

{{< callout type="info" >}}
**Полезно знать**

- Выбирайте Service inbound отдельно, не добавляя к нему другие теги.
- Для ручного выбора входящих подключений не используйте `setservice-*`.
- Подробные шаги настройки сервиса смотрите в руководстве со страниц Nodes/Services.
{{< /callout >}}
