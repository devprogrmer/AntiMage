<span id="admin-roles"></span>

Доступ администратора определяется ролью и назначенными ей разрешениями. Для владельца используйте Full Access, для операционных задач — Sudo, для партнёров — Reseller, а для ограниченной поддержки — Standard. Предоставляйте только необходимые разрешения и регулярно проверяйте лимиты.
