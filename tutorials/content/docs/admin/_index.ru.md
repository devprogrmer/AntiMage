Раздел администрирования содержит общесистемные операции. Он доступен только администраторам с ролью `sudo` или `full_access`, поскольку изменения могут затронуть инфраструктуру, разрешения и общие сервисы.

## Руководства

- [Автовыбор сервиса по входящему подключению](service-auto-inbound/) — автоматически назначайте сервис по тегу входящего подключения.
- [Резервное копирование через Telegram](telegram-backup/) — подключите бота и настройте расписание.
- [Узлы](nodes/) — сначала создайте запись узла в панели, затем установите агент с отдельным комплектом сертификатов.
- [Общие порты HAProxy](haproxy/) — направляйте трафик Xray, TCP-сервисов и сайтов через общие порты.
- [Администраторы](admins/) — создание администраторов и настройка лимитов.
- [Роли администраторов](roles/) — уровни доступа и их назначение.

{{< callout type="warning" >}}
Перед изменением узлов, ролей или общих интеграций проверьте цель операции и сохраните актуальную резервную копию.
{{< /callout >}}
