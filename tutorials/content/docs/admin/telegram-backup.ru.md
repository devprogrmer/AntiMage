<span id="section-telegram-backup"></span>

Настройте автоматическую отправку резервных копий панели в Telegram.

## Порядок действий

1. Создайте бота через BotFather и храните токен в секрете.
2. Создайте приватную группу для резервных копий и добавьте туда бота.
3. Сначала активируйте бота в панели, затем включите резервное копирование.
4. Отправьте тестовую резервную копию вручную и убедитесь, что группа получила файл.

{{< callout type="info" >}}
Используйте приватную группу только с доверенными администраторами. Не отправляйте токен бота пользователям или в публичные чаты. До включения расписания выполните тест отправки из панели.
{{< /callout >}}

## Создайте бота через BotFather {#section-telegram-backup-botfather}

BotFather — официальный инструмент Telegram для создания и управления ботами.

1. Откройте Telegram и найдите `@BotFather`.
2. Запустите чат и отправьте `/newbot`.
3. Укажите отображаемое имя, например AntiMage Backup.
4. Задайте уникальное имя пользователя, оканчивающееся на `bot`, например `antimage_backup_bot`.
5. Скопируйте выданный токен и сохраните его в надёжном месте.

{{< callout type="info" >}}
Токен — это пароль бота. Любой, кто его получит, сможет управлять ботом.
{{< /callout >}}

## Создайте группу резервного копирования {#section-telegram-backup-group}

1. Создайте новую группу с понятным именем, например Panel Backups.
2. В настройках группы включите режим форума — для резервной группы он обязателен.
3. Добавьте созданного бота в группу.
4. Если панели требуется разрешение на отправку сообщений и файлов, назначьте бота администратором.
5. Перед проверкой соединения отправьте в группу обычное сообщение.

Сохраняйте группу приватной. Если панель запрашивает ID чата или группы, используйте встроенную проверку или определение Telegram, если оно доступно.

## Включите резервное копирование в панели {#section-telegram-backup-panel}

1. Откройте настройки Telegram/бота и активируйте бота с токеном BotFather.
2. Проверьте, что бот отправляет тестовое сообщение в группу.
3. Откройте **Settings → Telegram → Periodic backup** и включите копирование в Telegram.
4. Нажмите общую кнопку **Save Settings**, затем **Send backup now**, чтобы проверить доставку файла.
5. После успешного теста оставьте запланированное копирование включённым.

Если файл не приходит, проверьте права бота, ID группы и правильность скопированного токена.
