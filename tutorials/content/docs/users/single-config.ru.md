Если нужна отдельная конфигурация, а не вся подписка, откройте вкладку Links.

## Порядок действий

1. На странице Users нажмите значок редактирования пользователя.
2. Откройте вкладку **Links**.
3. Нажмите кнопку QR-кода или копирования нужной конфигурации.

{{< callout type="info" >}}
**Полезно знать**

- QR-код удобен для передачи на телефон, копирование — для отправки в сообщении.
- Если ссылка подписки не работает, отдельная конфигурация может быть запасным вариантом.
{{< /callout >}}
