В поле поиска страницы Users можно вставить почти любые данные пользователя.

## Порядок действий

1. Вставьте URL подписки (токен, ключ или `имя/ключ`) в поле поиска.
2. Вставьте ссылку конфигурации (`vless`, `vmess`, `trojan` или `shadowsocks`), чтобы найти владельца.
3. Также можно искать по UUID, ключу учётных данных или исходному токену.

{{< callout type="info" >}}
**Полезно знать**

- Если пользователь не может подключиться, вставьте его точную ссылку конфигурации — так учётную запись проще найти.
- Поиск принимает как отдельные значения, так и полные URL.
{{< /callout >}}
