Создайте учётную запись и передайте ссылку без работы с сервером.

<p class="am-panel-actions"><a class="am-panel-button" href="#" data-panel-route="/users">Открыть пользователей</a><a class="am-panel-button" data-primary="true" href="#" data-panel-route="/users" data-session-key="openCreateUser" data-session-value="true">Создать пользователя</a></p>

## Порядок действий

1. На странице Users нажмите **Create user**, чтобы открыть форму.
2. Укажите имя, состояние (active или on hold), срок действия и лимит трафика.
3. Выберите сервис и входящие подключения, по которым будет сформирована ссылка.
4. При необходимости задайте лимит IP-адресов и добавьте заметку.
5. Включите **Auto Renew**, если нужно автоматическое продление.
6. Сохраните учётную запись и отправьте пользователю ссылку или QR-код.

{{< callout type="info" >}}
**Полезно знать**

- Состояние on hold позволяет подготовить доступ заранее и начать отсчёт после первого подключения.
- Добавьте короткую заметку, чтобы помнить назначение учётной записи.
- Лимит IP-адресов 1–2 затрудняет совместное использование ссылки.
{{< /callout >}}
